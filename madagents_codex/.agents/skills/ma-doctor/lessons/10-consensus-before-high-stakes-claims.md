# 10 — Consensus before high-stakes claims

> A single agent's claim is a hypothesis. N independent agents converging is a far stronger signal — wait for it before acting on a high-stakes claim.

The probability that five *independent* judges all make the same mistake is much lower than any
one being wrong, so a high-stakes decision waits for independent convergence rather than acting
on a lone signal. The discipline carries a concrete threshold in the source (enter only when a
strong supermajority — e.g. four of five — independently agree), and it is the same idea as an
adversarial judge-panel: one claim is a hypothesis; a panel that converges is corroboration.

## In a harness like this

A single consultant's claim is a hypothesis; independent convergence is the stronger signal that
licenses acting on a consequential claim. The interactive-product lens keeps it proportional —
reserve the full panel for claims that warrant it and answer the easy thing directly
(fast-where-it-can, accuracy-always), rather than convening five reviewers for every utterance.
Pairs with lesson 09 (the convergence only counts if the judges are independent).

## Where the books say it

- **Polymarket** — §05. The basket method: follow the consensus of a portfolio of wallets rather than copying any single one, entering only when a strong supermajority (around four of five) independently enters the same market, because five independent judges are far less likely to share one mistake.
- **Hermes** — §17. Independent samples plus an aggregator — N agents on the same task, the aggregator picks or merges.
