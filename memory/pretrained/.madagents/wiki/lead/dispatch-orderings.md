# Common multi-slice dispatch orderings

- **LO process+launch**: process-syntax → (coupling-order/diagram-filter/polarization if used) → diagram-enumeration → output → param-card/scales-pdf/kinematic-cuts → launch/phase-space/numerical.
- **Chain decay**: chain-decay (parse + onshell) → bw-window (runtime window) → phase-space (channels). Watch parser-acceptance≠attachment.
- **Off-shell decay window** (sub-threshold parent H→ZZ*/WW* at 125, OR heavy-parent→heavy-daughter H→tt* at 250): bw-window first to **derive** `bwcutoff` from the kinematic floor (`(m_pole−floor)/Γ`; floor=0 leptonic, =m_W+m_b for top→bW) — never default-15, never memorised-50 — then chain-decay (topology), then param-card (non-default parent mass), then physics for regime. Full playbook: `offshell-bwcutoff-derivation.md`.
- **NLO**: nlo-syntax + nlo-model (model capability) first → madloop + fks → nlo-export → amcatnlo (runtime). Dispatch broadly; NLO touches all six (see nlo-fanout.md).
- **EFT**: eft (truncation + restriction trap) → coupling-order (NP syntax) → ufo/restriction (operator pruning). See eft-smeft-fanout.md.
- **EFT polynomial-order bin isolation** (ask for σ_SM / σ_int linear / σ_quad quadratic / inclusive, or any `NP^2==`/`NP^2<=` constraint): eft FIRST (UFO's NP-per-insertion `p` → bin label; which restrict card keeps the operator; operator block/lhacode; QED-order of its couplings) → bin constraint [LO → coupling-order `NP^2==2p` single-run; NLO `[QCD]` → nlo-syntax+amcatnlo `NP^2<=p` + antisymmetric subtraction, `==` rejected] → restriction (removed≠small precondition) → param-card (zero ALL other WCs) → kinematic-cuts/scales-pdf/phase-space (mmll / NLO-PDF / sde_strategy=2) → physics. Discriminator is σ-vs-sign-of-c parity + matrix-source GC/JAMP fingerprint, NEVER "it parsed/ran." Full playbook: `smeft-order-bin-isolation.md` (sibling of coupling-vertex-viability + removed-coupling-not-small).
- **Decay rates / widths**: the six-slice lifecycle (ufo declare → restriction restore → param-card store → madwidth compute → bw-window/madspin/phase-space consume) — see decay-widths-lifecycle.md. For "compute the width": madwidth → param-card (AUTO write-back). For "why did my width come out 0 / get ignored" walk the lifecycle (usually the `'auto'` sentinel was never resolved → a literal `0.0` reaches the BW window / MadSpin / chain-σ BR denominator). For "I edited a mass and the chain σ is wildly off / BR>1" → stale-width-after-mass-edit: madwidth (regenerate) + phase-space (BR denominator). See derived-quantity-staleness.md.
- **Missing contribution / "removed ≠ small"** (a coupling/flavor the user expected gives nothing, or only one of several survives, under restrict_default): restriction (the removal — `RestrictModel`, sm-* variant survey) → diagram-enumeration (NoDiagramException for a lone zero-diagram process, OR a SILENT zero-diagram-subprocess drop inside a multiparticle expansion) → model-loader (the model-load-time fix: `sm-lepton_masses`). The fix is NEVER a `set`/param-card edit. See removed-coupling-not-small.md.
- **Coupling/vertex viability at a benchmark** (BSM/SM signal hinges on a coupling the chosen point zeroes — explicit fermiophobic `cq=0`, or derived decoupled-μ → Zχ̃χ̃→0 — OR a "which vertex enables this / why is my σ off" vertex-ID, OR guessed BSM particle names; run is clean, diagram count UNCHANGED, σ silently collapses): ufo (vertex present-vs-value) → diagram-enum (count unchanged is expected; gg-zero; leg-counting) → for a decay vertex, madwidth (`compute_widths` partial width/BR is the discriminating artifact) → for a derived mixing coupling, param-card (NMIX is card-read, never recomputed — supply a consistent matrix from an external diagonalizer) → process-syntax (BSM names from the model, case-insensitive per-model) → eft (SM dim-4 vs aTGC/dim-6) + model-loader (default `p` has no photon) for the false-attributions → physics (spectrum→coupling + no-viable-channel judgments). Discriminator is σ/partial-width/BR, never "it ran." See coupling-vertex-viability.md (sibling of removed-coupling-not-small: count CHANGES there, UNCHANGED here).
