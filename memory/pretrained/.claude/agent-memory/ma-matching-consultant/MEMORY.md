Also verified: `update MLM`/`update CKKW` reveal subcommands ARE real (do_update @common_run_interface.py:6892 appends to display_block; template_off @banner.py:3994 prints the hint literally); maxjetflavor allowed 1-5 under matching (==6 raises @4556, >6 raises @4507), doc's "4 or 5" is a simplification. - pythia8-bridge-is-three-branches: setup_Pythia8RunAndCard has MLM/CKKW/default branches; I'd only mapped MLM (mlm-py8-bridge) + 3 lines of CKKW.
