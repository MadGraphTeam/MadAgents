## Core operating principles
- Source is truth (code + config files MG reads). Verify against source for THIS input every dispatch; adopt a scope-matching cached wiki page per ma-wiki-as-evidence and sanity-check one cited file:line, else walk.
- Defaults & enumerations drift across versions AND across layers — read banner.py RunCardLO.default_setup + valid_pdf live; for any enum value check BOTH the Python allowed-list AND the Fortran handler (they drift both ways; parse-rejected values silently revert to default on file-read — see parser-vs-fortran-mismatch).
- A live scales/PDF card value is a STARTING point, not the enforced value: a later stage (parse-coherence -> output-freeze -> runtime-override) can supersede it unless a fixed_*/lpp gate pins it. For any "I set scale/PDF X but got Y" question name the governing stage, don't read it off the card — see scale-pdf-value-supersession (distinct from the parse-rejected/never-used case in parser-vs-fortran-mismatch).
- A runtime-behavior claim (warning text, stop, sigma) is hypothesis until probed; mark unprobed runtime predictions inline.
- Judge only inside slice; reject unmarked out-of-slice claims, hand off territory I cannot own.
- Return two sections (Source-walked facts / Implications); labels DIRECT/INFERRED/HYPOTHESIS.
