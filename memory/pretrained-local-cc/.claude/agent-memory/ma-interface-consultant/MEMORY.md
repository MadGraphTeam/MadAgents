## Recent lessons (FIFO, max 5)
- Plugin REPL (MadDM `MadDM>` / `python bin/maddm`) is the `--mode` plugin-interface path in disguise. Plugin `PLUGIN/<name>/__init__.py` exposes module-level attrs: `new_interface` (Cmd subclass=own REPL, or None), `new_output` (dict format→exporter), + `latest/minimal/maximal_mg5amcnlo_version`. `mg5_aMC -m <name>` (bin/mg5_aMC 169-187) imports `PLUGIN.<name>`, requires `new_interface` non-None (else warn+exit), builds `new_interface(mgme_dir=...)` as the cmd object → plugin's do_* ARE new REPL commands (`define darkmatter` etc.=plugin-internal=GAP). `install <name>` (madgraph_interface 6835-6858, installation slice owns cmd) writes executable `bin/<name>.py` that just re-invokes `mg5_aMC --mode=<name>` (release bakes `-O`, dev `-tt`) → `python bin/maddm.py`=`mg5_aMC --mode=maddm`. `install_plugin=['maddm','maddump','MadSTR','cudacpp']`@6484. `new_output`-only plugin used via `output <name>` (from_plugin_import 1714/2590), NOT `-m`. page: master-multiplexer-plugins.
- ControlSwitch forced consistency-override is NOT announced by any warning/print. check_consistency (extended_cmd.py 2795-2919) only logs debug (2827 dropped suggestion) / critical (2909 fixpoint fail); the forced value goes into `inconsistent_keys` (2919), NOT into `self.switch`. Effective value surfaces via `answer` property (2725 `out.update(inconsistent_keys)`) and `get_cardcmd` (2602 reads self.answer) — so the FORCED value drives card cmds. Interactive: next `create_question` redraw shows `chosen < replacement` arrow (3219) via postcmd(2728) — visible but not warned. Scripted/-f: no redraw → truly silent. Concrete shower/detector rules live OUTSIDE my slice in madevent_interface.py AskRun: consistency_shower_detector (623, shower=OFF→detector OFF), consistency_detector_shower (720, Delphes+non-PY shower→Pythia8). Precedence = last-set axis is trigger (last_changed 2799/2877). page: controlswitch-widget.
- LHAPDF config = THREE keys (options_configuration 3082-3085; defaults read fresh at coordinate): bare `lhapdf` is the ACTIVE key all consumers read (6238/6783/9746); `lhapdf_py2`/`lhapdf_py3` (None sentinel) are py-version INPUTS. TWO-STAGE resolve in set_configuration: (1) parse loop (7405) — `lhapdf_py2/_py3` NOT in set2-dispatch list → stored RAW; only bare `lhapdf` dispatches set2_ at parse. (2) reconcile loop, final=True only (7415/7518-27) — for `lhapdf_py3/_py2` non-None → `do_set(key val --no_save)`→`set2_lhapdf_py3/_py2` (aliases of set2_lhapdf 8451-52); set2_lhapdf (8410): `_py2`-suffix→to_do=False (drops py2 when running py3), else validates+sets BOTH `lhapdf` and the `_pyN` key; honors inline `--python=X.Y` filter. So `lhapdf_py3=/custom` DOES promote to active `lhapdf`. Template ships `_py2/_py3` COMMENTED (mg5_configuration.txt:193-4)→None (commented-until-install); a post-install config file instead carries an UNCOMMENTED bare `lhapdf =` line (install-written; `advanced_install` lhapdf6@6360-62 sets lhapdf_py3 then lhapdf=py3) — so verify install-file state fresh, don't assume the template's commented form. page: config-system.
- Card-dialogue `update <block>` valid names = `[b.name for b in run_card.blocks]` (do_update@6892, update_block built common_run:5246) — NOT a hardcoded list. LO block names = ion_pdf beam_pol syscalc ecut frame eva_pdf mlm ckkw psoptim pdlabel fixed_fact_scale RUNNING (read fresh at banner.py:4190-4192); NLO run_card only ion_pdf+RUNNING, so `update mlm`/`update beam_pol` are LO-ONLY. Heavy-ion block name is `ion_pdf` (not "heavy_ion"). `set` on a HIDDEN param needs no reveal (run_card.keys() includes hidden_param). page: card-dialogue-set-update.
- `display` model-inspection subjects (particles/interactions/multiparticles/parameters/coupling_order/modellist) are ALL MADGRAPH-prompt-only + require `_curr_model` (check_display 967/971-2: "No model currently active"). Output content (do_display 3576+): bare `display particles` = NAMES ONLY (name/antiname pairs, no PDG/mass/spin); PDG+mass+spin needs arg form `display particles <name>`→nice_string (3601-11). `display parameters` DOES separate external (key ('external',), sorted first via key_sort=-1, 3682-3) from internal, under `parameter type:` headers. `coupling_order` token is singular. `display modellist`(3875, also accepts `model_list`) = catalog of IMPORTABLE models (MG5DIR/models+PYTHONPATH+online DB), NOT loaded-model inspector.
