# Card read/write path (`$MADGRAPH_INSTALL/models/check_param_card.py`)

## `ParamCard.read(input_path)` — L338
Accepts a file path, a `\n`-string (StringIO), or an open file/iterable. Line loop L351:
1. `line.strip()`; skip blank or `#`-leading lines (L353-354).
2. `line = line.lower()` (L355) — **everything is lowercased before dispatch**.

Four entry types dispatched in this order:

### 1. `BLOCK <name> [Q=<scale>]` — L356-360
`line.startswith('block')` → new `Block()`, `load_str` parses name + optional Q-scale, appended; becomes `cur_block`.

### 2. `decay <pid> <width>` — L362-372
`line.startswith('decay')` → finds/creates the single `decay` block; a `Parameter` is loaded from `line[6:]` (strips the literal `decay ` prefix) via `load_str`. Width value may be a float or the string `auto`.

### 3. `xsection ...` — L374-377
`line.startswith('xsection')` (or once `cur_block=='notparsed'`) → appended verbatim to `self.not_parsed_entry`; **never parsed**. Sets the sticky `cur_block='notparsed'` so subsequent lines also pass through verbatim. Written back unparsed by `write()`.

### 4. Decay-table sub-lines — L383-395
When `cur_block.name == 'decay'` and a non-decay line follows, a fresh `Block('decay_table_<pid>')` is created keyed on the last-seen decay pid and stored in `self['decay'].decay_table[id]` (L383-387). Subsequent lines load via `Parameter.load_decay` (BR + daughter pids). `InvalidParamCard` on append is swallowed (L394-395).

### Fallthrough — generic block param L396-404
Otherwise `Parameter.load_str(line)`; on `InvalidParam` logs `Block "%s" has line "%s" that is not in slha1 format: line is ignored` (L402) and **drops the line** — does not abort the read.

`cur_block is None` (a param line before any BLOCK) is silently skipped (L380-381).

## `ParamCard.write(outpath=None, precision='')` — L544
- `text = self.header` (the `## PARAM_CARD AUTOMATICALY GENERATED BY MG5` banner, L319-322).
- Blocks emitted in `order_block()` order (insertion order, L548).
- `not_parsed_entry` appended verbatim at the end (L552).
- `outpath=None` returns the string; str path opens+writes; else `outpath.write` (test hook).

## A SECOND, non-`ParamCard` write path for widths: `update_width_in_param_card`
`$MADGRAPH_INSTALL/madgraph/interface/madevent_interface.py:2998` `@staticmethod update_width_in_param_card(decay_info, initial, output)` rewrites a param_card by **raw string/line manipulation — it does NOT use the `ParamCard`/`Block`/`Parameter` classes at all.** It is the writer for the `calculate_decay_widths` / `compute_widths --output` path (callers: madevent_interface.py L2993; madgraph_interface.py L9917, L10019). Behaviour:
- Reads `initial` as `.split('\n')` line list; **pops every existing `decay`/DECAY block** (while-loop L3012-3053; `param_card.pop(line_number)` L3017 for the DECAY header, L3030 for BR rows), parsing each DECAY total width and its `# BR NDA ...` sub-lines into `decay_info` (merging with the passed-in computed dict). Malformed BR/decay lines are `try/except`-skipped — same lossy tolerance as the `ParamCard` read.
- Keeps the **whole comment text after the first `#`** of each old DECAY line (`comment[int(line[1])] = ' '.join(line).split('#',1)[1]`, L3019 — `split('#',1)[1]` is everything past the first `#`, not just the first token); a DECAY line with no `#` gets `''`. That preserved string is re-emitted as the `# <comment>` on the regenerated `DECAY` line (L3065). The old per-BR-row annotations are NOT preserved.
- Trims trailing blank/`#` lines (L3055-3056), then **appends a fresh `#      Decay widths      *` section at the END of the card** (L3058-3076): one `DECAY %i %e # <comment>` per pid (sorted ascending by pid, L3062/3065), then header `#  BR             NDA  ID1    ID2   ...` (L3069) and the BR rows sorted **descending by BR** (L3071-3076). **Exact row format L3072** `"   %e   %i    %s # %s"` → BR in **exponential `%e`** (e.g. `1.000000e+00`, NOT plain `1.000000`), NDA `%i`, daughter pids **double-space-joined**, plus a **trailing `# <partial-width>` comment** (val[0]*width, L3075). The total-width line L3065 `"DECAY  %i   %e # %s"` carries as `# %s` the **preserved comment from the old DECAY line** (the model width-NAME e.g. `WT`/`WH`, NOT a literal "total width"). Complex widths via `.real` (width L3065, BR L3070). (Correction to a common mis-format: BR is exponential and each row has a trailing partial-width comment; the total-width comment is the width parameter name.)
- Writes the joined lines to `output` (L3075-3077). **In the `calculate_decay_widths` flow the output is `Events/<run_name>/param_card.dat`, NOT the operative `Cards/param_card.dat`** (L2994-2995) — the operative card is the read source only. The `compute_widths --output` callers can write in place (to `opts['output']`).
Caution: because this path strips and re-appends the DECAY blocks, a card it rewrites has its decay section relocated to the bottom and reformatted — block ordering and comments differ from a `ParamCard.write()` round-trip. Two distinct width-write mechanisms coexist: `ParamCard.write` (class-based, order-preserving) and this string-based appender.

## `create_diff(new_card)` — L560
Emits `set param_card <block> <lhacode> <newval> # orig: <oldval>` lines for params differing by > 6-digit tolerance (`misc.equal`, L570); also handles block `scale` changes (L574-578). This is the source of the `set param_card ...` syntax.

## Cautions
- The whole read is **lossy-tolerant**: malformed param lines are warned-and-dropped (L402), not fatal. A typo'd lhacode silently vanishes from the loaded card; the value then comes from model default at inc-file time.
- `xsection` lines round-trip but are opaque — never rely on read to validate them.
- Comments are parsed and re-emitted; `analyze_param_card` (L415) extracts parameter NAMES from the comment text. This is reliable on `*_default.dat` but explicitly "dangerous on the user-defined card" (docstring L419-421) because hand edits break the comment format.
