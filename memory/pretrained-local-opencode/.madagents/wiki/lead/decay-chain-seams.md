# Decay-chain cross-slice seams

- **`onshell` field** is shared by chain-decay (sets True) and `$` diagram-filter (sets False). `decayBW.inc` booldict `{None:0,True:1,False:2}`. Route the writing-side question to whichever *set* the flag. Semantic-vs-placeholder: of the `onshell=False` writes, only `diagram_generation.py:793` (forbidden s-channel) is *semantic* and survives to decayBW value `2`; `:214`/`:244` write `False` as base-`DiagramTag` reconstruction placeholders overwritten at `CanonicalConfigTag` (`helas_objects.py:534`) — don't cite them for a `value 2`. Route onshell-False-provenance to `../consultants/ma-chain-decay-consultant/cautions.md`.
- **BW window**: chain-decay/diagram-filter set `gForceBW`; bw-window owns what `bwcutoff`/`cut_bw` *do* with it at runtime; phase-space owns the integration-time `set_peaks` mapping. Three slices, one mechanism — split by "set the flag" vs "runtime window" vs "PS channel". Provenance split: `gForceBW` is the static window *scale* in `decayBW.inc` (None→0/True→1/False→2); `lbw` is the runtime cut *direction*, NOT in `decayBW.inc` — set per-config by a base-3 `DeCode` in `madevent_driver.f:347`. The role-card "decayBW.inc provides gForceBW and lbw" is a conflation. Route lbw-origin → `../consultants/ma-bw-window-consultant/bw-gforcebw-lbw-provenance.md`. (Probe-confirmed canonical two-level tt̄ cascade: four decay resonances `=1`, s-channel production `=0`, t-channel no entry.)
- **Generate-line chain ↔ MadSpin splice**: a `>`/comma chain on `generate` and a MadSpin `decay` card are two attachment paths that do NOT compose freely. MadSpin's `get_proc_with_decay` (`MadSpin/decay.py:2967-3035`) keys on the existing chain's comma count: **0 commas → append; 1 comma → distribute; ≥2 commas with parens → hard `Exception('too much decay at MG level')`**. A nested/parenthesized generate-line chain forecloses any later MadSpin decay of its inner products → `../consultants/ma-madspin-interface-consultant/madspin-decay-chain-grammar.md`. **`@` collision:** a MadSpin `decay` line may carry `@<key>` for spin-correlation grouping (`decay.py:2850-2881`) — distinct from the production-line `@N` process-class tag. The card reader splits only on `;`/`#`/`\`, never on comma (`extended_cmd.py:1009`).
- **Decay-chain depth traps** (each an instance of "static output artefact ≠ operative runtime value"): (a) a plain (non-multiparticle) decay leg silently DROPS `diagram_filter` — `get_amplitude_from_proc(**opts)` swallows the kwarg (diagram-enumeration `decay-chain-amplitude.md`). (b) `NoDiagramException` in a decay-chain branch propagates UNGUARDED and kills the whole chain (diagram-enumeration `multiprocess-crossing-mirror.md`). (c) the flattened full-depth final state (IDUP/`leshouche.inc`/subprocess naming/`IdentifyMETag`) is `Process.get_legs_with_decays`, not the core legs — chain-decay `legs-with-decays.md`. (d) an `auto`-width chain parent keeps its named width param (restriction never zeroes it → `log10(2N)` placeholder), so the propagator gets a BW config slot but the numeric value is `0.0` until `compute_widths` runs → a zero-width BW if auto never computed (madwidth `chain-parent-width-for-propagator-bw.md`).
- **Which guard rejects a "perturbed/illegal-order decay chain" depends on the Switcher, NOT a single cmd-layer gate.** The determinant is bracket presence/placement, resolved by `extract_process_type` (nlo-syntax slice) **before** any `do_add`:
  - **Perturbed decay — a REAL `[...]` bracket** classifies `('NLO',…)` regardless of placement (greedy `loopRE`, `master_interface.py:175`) and switches the interface to aMC@NLO (`:271-278`). The operative rejection is then inside aMC@NLO's `do_add`: bracket *in a sub-decay* → `amcatnlo_interface.py:523` *"Decay processes cannot be perturbed"* (no period); bracket *on the core* → `loop_interface.py:247` *"ML5 cannot yet decay a core process including loop corrections."*. Route to nlo-syntax (switch) → amcatnlo / madloop (guard). `../consultants/ma-nlo-syntax-consultant/switcher-extract-process-type-predispatch.md`.
  - **DEAD layers for a real bracket:** `madgraph_interface.py:3296-3297` (with period) and `diagram_generation.py:1379` (two words) — both unreachable; a probe calling `DecayChainAmplitude` directly sees the wrong (`:1379`) string. See diagram-enumeration `decay-chain-amplitude.md`.
  - **Empty `[]` bracket + comma** classifies `('tree',…)` → `madgraph_interface.py:3283-3289` *"…cannot be used in cunjunction with decay chains."* — needs an EMPTY bracket, not a real one (process-syntax `decay-chain-comma-handoff.md`).
  - **Squared / negative coupling-order on a decay** (no bracket → tree route): rejected at `madgraph_interface.py:3301-3304` / `:3305-3307`, no enumeration counterpart — these DO fire at the cmd layer; route to process-syntax / chain-decay.
  - The entry parser runs `extract_process` once per chain-tree node on a bare `>`-substring (multiparticle expansion is per-segment) — process-syntax `decay-chain-comma-handoff.md`.
