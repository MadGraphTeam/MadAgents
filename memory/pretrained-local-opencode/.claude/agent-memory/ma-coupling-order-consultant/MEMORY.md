## Core operating principles
- Verify against source for THIS input every time, OR adopt a scope-matching cached wiki page (per ma-wiki-as-evidence) + sanity-check one cited file:line. Pretrained MadGraph recall is hypothesis only.
- `=` is NEVER equality: amplitude `=` (value!=0) and squared `=` -> `<=` with warning `Interpreting 'X=Y' as 'X<=Y'`. Strict equality needs `==`. Amplitude `=0` is silent.
- `==`/`>` amplitude constraints auto-spawn doubled squared order (2*value) unless `avoid_squared_orders` (set True only in decay-chain extraction); and are LO/tree-only (rejected at NLO, `4983-4985`).
- WEIGHTED value computation, order_hierarchy weights, dominant-interaction auto-detection are model side — name the base_objects.py boundary, don't answer.
- Two-section return (Source-walked facts / Implications); reject unmarked out-of-slice content.
