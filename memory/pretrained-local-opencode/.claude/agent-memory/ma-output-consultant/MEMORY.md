## Recent lessons (FIFO, max 5)
- helrec-runcard-vs-outputflag + matrix_optim-myth: `hel_recycling` is BOTH a hidden RunCardLO param (banner.py:4454, default True, include=False → RUNTIME deactivation only; comment "code needed to be generated with such optimization") AND the output-time GENERATION flag `--hel_recycling=False` (do_output :9125). Run_card False does NOT prevent generation/compile — so it does NOT cure an output/compile-time `Line truncated`; the fix is regenerate `output ... --hel_recycling=False`. Also: NO file named `matrix_optim.f` exists (grep=0); recycling emits matrix%d_orig.f + template_matrix%d.f → matrix%d.f. FortranWriter auto-wraps continuation lines (wrap column read at file_writers.py:201/349) so writer-emitted Fortran can't exceed the 132-char fixed-form limit; a real Line-truncated comes from writer-BYPASSING template/recycler code (mc-integration). (no-helrecycling-two-mechanisms.md Doc-myth section)
- helrec-me-exporter: don't equate "appends --hel_recycling=False to args" with "sets no_helrecycling in flaglist". The :9125 flaglist test runs ABOVE the :9132 me_exporter arg-append (guard at :9131), so me_exporter suppresses recycling only at the exporter opt, not the finalize :9707 P1N gate. Trace statement ORDERING, not just presence. (Generalized into do-output-flag-channels.md.)
- grouped-mode-runtime-mutation: the grouping criterion is the exporter's grouped_mode, but it is MUTATED to 'gpu' at runtime by `set group_subprocesses gpu` (class attr :7976) and by --me_exporter (instance :9504). Effective criterion != static class default. gpu path = madevent-key group + split_nonidentical_grouping (per-ME split + gpu naming); find_process_classes gpu key is dead for output. Don't read grouping behavior off the factory class alone.
- bias-tree-is-source-not-subprocesses: the BIAS module tree output copies live at Source/BIAS/ (dummy/ + ptj_bias/), NOT SubProcesses/BIAS (a common wrong assumption). copy_template brings it via the whole-Template/LO copy. Mandatory subroutine bias_wgt + common/bias/. ptj_bias formula (max_ptj/target)^power; params live in a `C parameters={...}` header comment, injected via Source/BIAS/bias.inc (banner include='BIAS/bias.inc'). Runtime lookup/parse is madevent_interface do_treatcards (launch slice), not output. (bias-module-output-layout.md)
- gpu-key-is-dead-not-finer: :9440 remaps grouped_mode 'gpu'->'madevent' before group_amplitudes, so find_process_classes' gpu key (:498) is never used on the output path. Fine-graining comes from split_nonidentical_grouping, not the key. Probe-confirmed (set group gpu: P1_uux_z/P1_ddx_z vs plain P1_qq_z). Don't infer "finer key -> finer grouping" from a key existing.
