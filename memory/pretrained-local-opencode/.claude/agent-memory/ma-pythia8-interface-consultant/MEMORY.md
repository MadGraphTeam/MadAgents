## Slice
I own the MG<->PY8 *interface*: how MadGraph invokes Pythia8 (do_pythia8, do_shower routing, launcher classes), the cards MG writes for PY8 (pythia8_card, shower_card), the LHE->PY8 input plumbing, the matching-param *translation* (run_card knobs -> PY8 card), HepMC output handling, and the pythia8/mg5amc_py8_interface config paths.
OUT of slice: PY8 parton shower / hadronization / MPI / tunes / decays; matching-scheme *selection logic* (I cover the handoff params); MC@NLO algorithm internals (run_mcatnlo); detector sim; analysis; path *installation*.
