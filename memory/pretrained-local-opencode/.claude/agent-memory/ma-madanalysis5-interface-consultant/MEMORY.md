## Recent lessons (FIFO, max 5)
- switch-key-vs-value + parton-before-shower: the launch ControlSwitch KEY is `analysis` (AskRun.to_control madevent_interface.py:502), the VALUE literal is `MadAnalysis5` — so `analysis=MadAnalysis5` is well-formed (matches check_analysis:766; shortcuts ma5/5/madanalysis5 also normalize). DOC-MYTH: "MA5 runs after Delphes/Pythia8" is true ONLY for hadron-level; PARTON MA5 runs BEFORE shower (generate_events order 2666-2670: parton -> shower -> hadron -> rivet). Both fire unconditionally as `--no_default`; detector=Delphes does NOT select parton/hadron — card-menu gates hadron card on shower!=OFF (6784). Formats: _default_parton_inputs=['*.lhe']; _default_hadron_inputs=hepmc/hep/stdhep/lhco/root (banner.py:5155-5156).
- layer2-not-all-quiet: "post-launch MA5 failure = quiet degrade" is OVER-BROAD. run_madanalysis5 reco runtag at 3281-3282 hard-RAISES MadGraph5Error when the reconstructed event file is missing (unconditional, no no_default guard). Trigger: any claim that Layer-2/post-launch MA5 failures all return-and-warn — check return vs raise per path.
- three-gate-no-plots: "MA5 produced no plots" has THREE distinct root causes at three lifecycle stages — path-unset (never offered), card-missing (silent skip / InvalidCmd), card-is-skip_analysis-default (loads but no-ops with INFO). Trigger: any "did MA5 run / why skipped / why nothing" question — walk all three gates in order (ma5-three-gate-availability page), don't stop at the first.
- cards-born-at-output-not-run: the operative `Cards/madanalysis5_{parton,hadron}_card.dat` are CREATED at OUTPUT/export time (export_v4.py create_MA5_cards copies the generated `_default.dat`, "turns MA5 on by default"), NOT at launch. LO writes parton+hadron, NLO/FKS hadron-only (independent corroboration of hadron-only-NLO). Standalone never. Trigger: any "where do MA5 cards come from / why absent" question — check the output-time gate (output-time-card-creation page), not just run-time.
- path-nulled-to-python-None: `madanalysis5_path = $MADGRAPH_INSTALL/None` in mg5_configuration is RESOLVED to python `None` at config-load (madgraph_interface.py:7441-7448 nulls it when `bin/ma5` missing OR is_MA5_compatible returns a reason) — PROBE-CONFIRMED `MasterCmd().options['madanalysis5_path']` is `None`, not the string. Don't treat the literal `None`-string as a truthy path. Same nulled value closes BOTH the output-time and run-time gates here.
