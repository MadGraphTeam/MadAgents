# 13 — Subagents are independent context

> A subagent's deepest value is its own clean context window — not just that it is a specialist.

Delegating a sub-task returns the finding without consuming or polluting the main session's
context. That — not "a specialist" — is the primary argument for a roster: each delegate gets a
clean window to work in, and the lead's window stays uncluttered, getting back a compressed
verdict rather than the full exploration. It is simultaneously a token-frugal argument and an
accuracy argument.

## In a harness like this

This is the load-bearing justification for the consultant roster. Each specialist source-walks in
its own context and returns a labeled answer, not the walk; the lead never inherits the
exploration, only the signal. The roster is not just "many experts" — it is many clean windows,
which is why a rich roster can stay frugal (pairs with lessons 17 and 20).

## Where the books say it

- **CC-Guide** — §08, on the core value of subagents — the deepest value is the independent context window: delegating returns the finding without consuming or polluting the main session.
- **OpenClaw** — §09. The Session Tree: a side-quest leaves the main session's context window untouched and, on completion, rolls back carrying only a one-line summary.
- **Hermes** — §09. Three-tier progressive disclosure lets hundreds of skills cost almost nothing day to day — the same isolate-and-summarize economy.
- **CC-Guide** — §11. Thin orchestrator, single-responsibility specialists — the lead routes and stays thin; each specialist owns one clear responsibility (the split buys clarity of ownership, not brevity).
